Rick and Morty API Search

Projeto desenvolvido em HTML, CSS e JavaScript consumindo a API pública do Rick and Morty.

Descrição

Aplicação criada para buscar personagens do desenho Rick and Morty utilizando a API oficial.

O usuário pode pesquisar personagens por ID ou nome, visualizar suas informações e navegar entre os personagens usando os botões de avanço e retorno.



Funcionalidades

✔ Buscar personagem por ID  
✔ Buscar personagem por nome  
✔ Exibir imagem do personagem  
✔ Mostrar nome, gênero, status e espécie  
✔ Botão Avançar 
✔ Botão Voltar  
✔ Consumo de API com fetch()  
✔ Uso de async/await



Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API Rick and Morty
